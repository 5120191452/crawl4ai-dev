## Module contents
@Module : ark_platform_adapt
Platform adaptation module refers to re-continuous integration (CI/distributed /…) The network-related components or functions used in the environment, which are responsible for supporting the docking work in the continuous integration process, the product platform adaptation module is an important part of the test system, thus realizing the adaptation of external automated processes

🐻@Version: 1.0.2 @update time: 2025/3/10 @Person Responsible: xiaoze

ꔷ When adding progress bars, tool names, basic data display, and additional information to the list in the pop-up window of the platform adaptation component, they will be added and focused on the end data.

ꔷ Support for configuring whether to display a pop-up window when the platform is launched.
