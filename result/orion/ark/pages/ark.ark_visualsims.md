## Module contents
@Module : ark_visualsims
@Date : 2025/10/09
@Version : V1.0.0
ark_visualsims is a unified visual automation execution component that provides end-to-end control capabilities from image capture, visual perception, target element recognition, to keyboard/mouse simulation. It is designed for visual automation scenarios such as automated testing and interactive simulation.
