Public contract for a one-to-one mobile automation session.
Contract-valid calls and invalid caller arguments return `(error_code, data)`. `error_code == 0` indicates success and `data` has the documented success type. On an expected failure, `data` is always `MobileErrorInfo`; callers branch only on the error code. `stage` identifies the failure site, `message` is the actionable summary, `source` identifies its subsystem, and native command context is retained in `native_return_code` and `raw_message`. `details` contains only failure-specific supplementary values. Unexpected implementation defects are deliberately not swallowed as ordinary device failures.
